# Project Charter - SeizeVoice

## Project Name

SeizeVoice

## Purpose

To create a website where people can discuss topics and join niche
communities without fear of judgment, and easily identify trustworthy
answers.

## Problem Statement

People struggle to find trustworthy discussions and communities for
their interests, and often stay silent instead of participating because
they fear judgment.

## Objectives

- Allow users to create and join topic-based communities
- Allow anonymous posting so users can share honestly without fear
- Allow the community to filter trustworthy answers through voting

## Scope

### In Scope (MVP)

- Topic-based communities
- Anonymous usernames
- Upvote/downvote system

### Out of Scope (for now)

- Search function
- Recommendation system
- Karma/reputation score
- Notifications
- Bookmarks
- Reporting/moderation tools
